# Викуська — романтический сайт

Сайт открывается сразу: регистрация, пароль, сессии и кнопка выхода удалены по просьбе владельца. React + Vite и Cloudflare Worker. Worker выдаёт файлы и принимает реакции для Telegram.

## Секреты бота

Cloudflare → Workers & Pages → нужный Worker → Settings → Variables and Secrets → Add → Secret.

| Name | Value |
| --- | --- |
| TELEGRAM_BOT_TOKEN | Полный токен от BotFather |
| TELEGRAM_CHAT_ID | Числовой ID твоего личного чата с ботом |

Name и Value заполняются отдельно, без кавычек и знака равенства. Пароль сайта и ключ сессии больше не нужны. Токен нельзя помещать в GitHub, public/config.json или переменные VITE_*. Сначала отправь своему боту /start. Chat ID берётся из message.chat.id во входящем обновлении. Если токен публиковался, перевыпусти его у BotFather.

## Запуск

Node.js 22.12+ или современный Node 24.

```powershell
npm.cmd ci
npm.cmd run dev
```

start.cmd также запускает локальный просмотр дизайна. Он не подключает сервер Telegram.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run worker:dev
```

Для локальной отправки Worker использует worker/.dev.vars с двумя секретами бота. Файл исключён из Git; его нельзя включать в архивы.

## Публикация в Cloudflare

```powershell
npx.cmd wrangler login
npx.cmd wrangler secret put TELEGRAM_BOT_TOKEN --config worker/wrangler.jsonc
npx.cmd wrangler secret put TELEGRAM_CHAT_ID --config worker/wrangler.jsonc
npm.cmd run build
npm.cmd run worker:deploy
```

Секреты вводятся интерактивно, не в строке команды. Настройку выполним вместе. GitHub workflow checks.yml проверяет тесты, сборку и dry-run Worker, но не публикует сайт. Весь сайт и API работают с одного адреса Cloudflare. Новый репозиторий ещё не связан с локальным проектом.

## Музыка и сообщения

Предоставленный MP3 — public/music.mp3. Название, исполнитель и адрес API — public/config.json. После замены MP3 собери и опубликуй новую версию. Звук запускается кнопкой.

Сервер разрешает только известные действия и Origin самого сайта. Проверяются UUID, скрытое поле ловушки, время заполнения и длина текста 1–1500 символов. Тело запроса ограничено 8 КБ. Durable Object ограничивает отправку: минимум 3 секунды между запросами IP, до 6 в минуту с IP и 60 в час суммарно. UUID предотвращает повторную обработку одной попытки.

Без регистрации и пароля любой посетитель сайта может использовать форму. Origin и ограничения снижают спам, но не удостоверяют личность. Токен остаётся исключительно на сервере. При необходимости усилим защиту формы через Turnstile.

Подтверждение отображается только после успешного ответа Telegram с ok: true, а не после одного нажатия. При ошибке текст сохраняется в поле. При потере ответа перед повторным нажатием проверь чат: новая попытка может дать повтор.

## Поиск сюрпризов
На странице есть приглашение искать четыре тайника и счётчик находок. Текстовые подсказки, автоматическая подсветка тайников и таймеры поиска удалены. Обычные декоративные анимации сохранены. После четвёртого мини-сюрприза открывается отдельное финальное письмо, его можно перечитать с первого экрана. Прогресс действует до обновления страницы.
